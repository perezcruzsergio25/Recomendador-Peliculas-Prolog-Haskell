## 5. Casos de Uso

### Caso de Uso 1: Búsqueda de Películas por Género
* **Actor:** Usuario
* **Descripción:** Permite al usuario obtener recomendaciones de películas filtradas según una categoría de género específica.
* **Flujo Principal:**
  1. El usuario selecciona la opción **1. Buscar por género** en el menú principal.
  2. El sistema solicita al usuario que ingrese un género (ej. *ciencia_ficcion*).
  3. El usuario introduce el género deseado.
  4. El sistema realiza la consulta y muestra en pantalla la lista de películas relacionadas.

---

### Caso de Uso 2: Búsqueda de Películas por Año
* **Actor:** Usuario
* **Descripción:** Permite al usuario filtrar la base de conocimientos para obtener títulos estrenados en o después de un año específico.
* **Flujo Principal:**
  1. El usuario selecciona la opción **2. Buscar por año** en el menú principal.
  2. El sistema solicita al usuario que ingrese un año (ej. *2010*).
  3. El usuario introduce el año de filtro.
  4. El sistema filtra la base de conocimientos y muestra las películas cuyo año de estreno sea posterior o igual al valor ingresado.
